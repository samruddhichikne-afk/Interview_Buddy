Interview Buddy is a web-based AI-powered mock interview platform designed to help students and job seekers practice interviews in a realistic environment. It uses camera + microphone + speech recognition to simulate real interview scenarios and provides instant feedback and analytics.

✨ Features
🔐 Google Authentication (Firebase)
👤 User Profile Management
🎤 AI Mock Interview System
📹 Live Camera + Microphone Recording
🗣️ Speech-to-Text Answer Capture
📊 Performance Analytics Dashboard
📁 Interview History Tracking
🎯 Topic-wise Weak Area Detection
💎 Modern UI (Glassmorphism + Animations)

🔥 Key Functional Modules
🔐 Authentication
Firebase Google Sign-In
Session handling
🎤 Speech Recognition
Uses browser Speech API
Converts spoken answers into text
📹 Media Handling
Uses navigator.mediaDevices.getUserMedia
Captures video + audio
📊 Analytics Engine
Calculates:
Average score
Weak areas
Performance trends
