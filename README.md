# 🚀 Interview Buddy – AI Mock Interview Platform

## 📌 Overview

**Interview Buddy** is a web-based, AI-powered mock interview platform designed to help students and job seekers practice interviews in a realistic, interactive environment.

It leverages **camera access, microphone input, and speech recognition** to simulate real interview scenarios while providing **instant feedback and performance analytics**.

---

## ✨ Features

* 🔐 **Secure Authentication** – Google Sign-In using Firebase
* 👤 **User Profile Management** – Personalized user data and preferences
* 🎤 **AI Mock Interview System** – Real-time interview simulation
* 📹 **Live Camera & Microphone Integration**
* 🗣️ **Speech-to-Text Processing** – Converts answers into text
* 📊 **Performance Analytics Dashboard**
* 📁 **Interview History Tracking**
* 🎯 **Weak Area Identification (Topic-wise)**
* 💎 **Modern UI/UX** – Glassmorphism design with smooth animations

---

## 🔥 Core Functional Modules

### 🔐 Authentication

* Firebase Google Sign-In
* Secure session management

### 🎤 Speech Recognition

* Uses **Web Speech API**
* Converts spoken responses into text in real time

### 📹 Media Handling

* Uses `navigator.mediaDevices.getUserMedia`
* Captures live video and audio streams

### 📊 Analytics Engine

* Calculates:

  * Average Score
  * Best Performance
  * Weak Topics
  * Overall Progress Trends

---

## 🧠 Interview Logic

* Questions are dynamically selected from predefined domains:

  * **HR**
  * **OOP**
  * **Java**
  * **SQL**
  * **Web Technologies**

* Each response is evaluated based on:

  * Word count (confidence indicator)
  * Topic-wise performance (weak area detection)

## 🎯 Objective

To provide a **smart, accessible, and practical platform** where users can:

* Practice interviews anytime
* Improve communication skills
* Identify weaknesses
* Track performance growth
